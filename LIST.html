    THREE TYPES OF HTML LIST

    1.UNORDERED LIST (ul) Used when the chronological sequence of items does not matter. Items are marked with BULLET POINTS by default.

    Parent container uses the (ul) tag

    Each individual item uses the list item or (li) tag.

    Bulltes styles can be changed with CSS list-style-type(ex. square or circle).

    Example:Groceries

    • Milk
    • Egg
    • Bread
    • Sugar
    • Coffee supplies
      • Coffee beans
      • Creamer
      • Sugar

      2. ORDERED LIST (ol ) Ordered list are used when the sequence of the items is important. Items are marked with NUMBERS by default.

      Parent container uses the (ol) tag

      Each individual uses the (li) tag

      Customize markers using the type attitude (ex.type="A"for letters, type =I for Roman numerals).

      Reverse numbering order using the reversed attribute.

      Change the start value using the start attribute.

        Example: Morning Routine

        1. Prayer
        2. Exercise
        3. Walking/running
        4. Eat breakfast
        5. Bath
        6. Work

        3.DESCRIPTION LIST (dl) Used for key-value, groceries, or terms and definitions. They do not use standard bullet points or sequential numbers.

        Parent container uses the (dl) or description list tag

        The term is wrapped in a (dt) or description term tag.

        The explanation is wrapped in a (dd) or description details tag.


        Example:PRAYER
        A solemn request for help lt expression of thanks addressed to God or an object to worship.
        EXERCISE
        Activity requiring physical effort, carried out to sustain or improve health and fitness
        WALKING
        Move at a regulat pace by lifting and setting dow each other foor in turn, never having both feet off the ground at once.
        BREAKFAST
        A meal eaten in the morning, the first of the day.
        BATH
        An act of process of immersing and washing one's body in a large container of water.
        WORK
        A purposeful mental or physical effort directed toward achieving a result, earning a livelihood, or producing a physical change.

          LIST TYPE HTML TAGS DEFAULT MARKER BEST USE CASE
